# Changelog

## 1.0.1 — DSH 0.1.2 compatibility

- Replaced the removed Client Runtime dependency with the DSH 0.1.2 UI renderer and Cordis context contracts.
- Fixed automatic contrast repair when a white foreground needs to become darker.
- Added a WCAG AA regression gate for every built-in light and dark preset.

## 1.0.0 — First release

- Local Skin Studio settings editor and reversible theme preview.
- dshskin/v1 storage, strict import validation, Typert Remote CRUD, active state.
- OKLab/OKLCH colour tools, image palette extraction, six presets, semantic derivation, audit, locks, history.
- JSON/plugin/PNG exports, accessibility-minded CSS and reduced-motion support.
